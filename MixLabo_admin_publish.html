🍓 Публикация рецептов / Rezepte veröffentlichen

Полученный через Formspree рецепт сначала проверьте. Затем внесите сюда название, состав и способ приготовления на двух языках. После проверки нажмите «Опубликовать на сайте» — страница обновится через Cloudflare. Резервная кнопка сохраняет файл recipes.html на компьютер. Данные черновиков хранятся только в этом браузере.

Заполни одну языковую колонку, затем нажми перевод: название, ингредиенты и приготовление заполнятся во второй колонке. Проверь перевод перед публикацией. Текст рецепта отправляется внешнему сервису MyMemory только после нажатия кнопки, без имени автора и почты. Бесплатный сервис имеет лимиты и требует интернет.

Изображение уменьшается автоматически и помещается внутрь рецепта. Никаких отдельных загрузок фотографий не требуется.

🚀 Публикация на MixLabo

Ключ вводится при публикации и не сохраняется в браузере или файле сайта. Не отправляйте его в чат.

Публикация загружает действующий recipes.html, сохраняет старые рецепты и добавляет новые. Никаких ручных загрузок GitHub при успешной автоматической публикации не требуется.

После загрузки файла ссылка будет: mixlabo.de/recipes.html. Кнопка «Рецепты» на главной странице уже работает.
